# 저장 자료 기반 검색과 근거 검사

질문에 맞는 고정 안내 또는 서버에 저장된 공식 자료를 찾아 모델 문맥에 넣는 모듈입니다. 실시간 웹 검색이나 전체 인터넷의 최신성 검증 기능은 아닙니다.

| 파일 | 역할 |
| --- | --- |
| `query.ts` | 검색어 정규화·의도와 후속 질문 처리 |
| `knowledge.ts` | 출처 메타데이터를 갖춘 고정 안내 검색 |
| `public-catalog.ts` | 저장된 정책·금융상품·창업 자료의 검색 문서와 FTS 조회 |
| `public-statistics.ts`, `indicators.ts` | 통계·지표 질문의 의도와 근거 처리 |
| `context.ts` | 크기가 제한된 모델 문맥, 출처 번호와 근거 기반 대체 안내 |
| `grounding.ts` | 답변의 인용·수치·확정 표현을 전달된 근거와 대조 |

원천 수집과 공용 캐시는 [public-data](../public-data/README.md), 모델 호출은 [ai](../ai/README.md), 법령 근거는 [legal](../legal/)과 연동합니다. 색인 구조 변경은 [drizzle](../../drizzle/README.md)에 있습니다.

공개 소스에는 실제 운영 카탈로그·DB가 포함되지 않습니다. 자료가 없거나 오래되었으면 현재 수치·정책을 만들어 채우지 않고 근거 부족·미연동 상태를 구분합니다. 원천의 지시문을 신뢰된 시스템 지시로 취급하지 않으며, 사용자 문맥은 해당 동의 범위 안에서만 사용합니다.

루트에서 `npm run test:rag`, `npm run eval:rag`로 회귀·합성 검색 진단을 실행할 수 있습니다. 이 결과는 생성형 모델 품질이나 최신 정책·법령 정확성 인증이 아닙니다. 상세 한계는 [평가 안내](../../evaluation/README.md)를 참고하세요.
