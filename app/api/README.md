# 웹 API 안내

이 폴더는 브라우저가 사용하는 서버 API입니다. 각 `route.ts`가 실제 요청 처리와 권한 검사를 정의합니다. 내부 Local LLM API와는 별개이며, 모델 토큰을 브라우저에 전달하지 않습니다.

## 기능별 위치

| 폴더 | 역할 | 접근 원칙 |
| --- | --- | --- |
| `auth`, `session` | 소셜 로그인 시작·콜백·세션 확인 | 일회성 상태/PKCE, 현재 약관 동의, 안전한 쿠키 |
| `account`, `profile` | 회원 정보·동의·계정 수명주기 | 현재 세션 계정에 한정 |
| `finance/snapshot` | 직접 입력 자산·부채·월 현금흐름 | 로그인 계정별 저장, 같은 출처의 JSON 변경 요청 |
| `ai` | 상담·대화·개인화 문맥 | 경로별 로그인/동의·요청 제한; 출처 확인 |
| `daily-guide` | 저장 자료와 직접 입력 장부에 기반한 오늘의 안내 | 익명/로그인 상태 구분, 장부는 현재 계정만 조회 |
| `phishing` | 문자·URL 위험 신호와 대응 안내 | 같은 출처 요청·크기/빈도 제한, 외부 평판 조회는 별도 동의 |
| `legal` | 공식 법령 조회·요약 | 공식 근거 및 요약 품질 정책 |
| `public-data` | 저장된 공식 자료·추천·갱신·`item-analysis` 항목 설명 | 읽기/사용자 기능/내부 수집 권한을 구분 |
| `developer` | API 제공자·설정·평가 관리 | 설정된 관리자 고유 식별자 필요 |
| `health` | 최소 상태 확인 | 공개 가능하되 비밀값·사용자 데이터 제외 |

같은 폴더 안에서도 읽기·쓰기 권한이 다를 수 있습니다. 정확한 메서드, 입력 필드, 오류 코드는 해당 `route.ts`와 회귀 테스트가 기준입니다. 경로 목록만으로 익명 호출 가능 여부를 추정하지 마세요.

## 인증과 비밀정보

- 외부 로그인은 `AUTH_MODE=external` 및 정규 HTTPS `APP_BASE_URL` 설정을 사용합니다. 제공자별 callback URL을 개발자 콘솔과 일치시키세요.
- `bora_session`은 `HttpOnly` 쿠키이며 HTTPS에서는 `Secure`가 적용됩니다. 세션 토큰 원문을 DB에 저장하지 않습니다.
- 사용자 ID는 요청 본문에서 신뢰하지 않고 인증된 세션에서 결정합니다. 관리자 권한은 이메일이 아닌 `DEVELOPER_ADMIN_IDENTITIES`의 `provider:subject`로 판단합니다.
- 변경 요청의 같은 출처 검사는 CSRF 방어입니다. 그것만으로 비브라우저 남용을 막거나 사용자를 인증하는 것은 아닙니다.
- 내부 수집 API의 Bearer secret과 Local LLM 토큰은 서버 전용입니다. 예제·스크린샷·브라우저 코드·URL query에 실제 값을 넣지 마세요.
- HTTP 200만 확인하지 말고 JSON의 준비 상태·인증 여부·부분 수집 여부도 확인하세요. 401/403/413/429/503은 서로 다른 원인입니다.

## 변경 시 검증

저장소 루트에서 `npm test`, `npm run test:parity`, `npx tsc --noEmit`를 실행합니다. 인증·다른 사용자 접근·동의·과대 요청·DB 장애·동시 요청도 정상 요청과 함께 테스트하세요. 실제 회원 데이터로 쓰기 테스트를 하지 말고 격리 DB와 합성 계정을 사용합니다.
