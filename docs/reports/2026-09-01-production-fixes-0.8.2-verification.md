# 운영 문제 수정 및 0.8.2 검증 기록

확인 시각: 2026-09-01 03:00 KST 전후. 대상: https://borabridge.com.

## 적용 결과

- 실행 중이던 0.8.1의 미커밋 변경을 기준으로 수정했다. 구버전 GitHub 코드로 되돌리지 않았다.
- 원격 서버에 최종 0.8.2를 적용했다. 설치 대상 55개 파일의 SHA-256과 실행 산출물 전체 지문이 검증된 복사본과 일치한다.
- 첫 배포 후 수정 대상이 아닌 기존 소스 445개도 기준 지문과 일치함을 확인했다.
- 계정, 대화, 자산 장부, 동의 및 API 키 설정값을 교체하지 않았다. Git 커밋·push·master 병합은 이번 작업에서 실행하지 않았다.
- 주요 적용 내용: 전국 상권 조회의 일자 형식/할당량 처리, 로그인 창 재등장, 홈 집계 일관성, 개인화 OFF 시 전체 정책 표시, 전체 공고 기반 창업 지도/검색/페이지 처리, 정책 날짜 정규화, 질문 의도별 검색 근거, 법령 원문 발췌 및 핵심 순서 후보 선택.
- 최종 보완으로 법령 주제·언어 변경과 화면 종료 시 오래된 요청을 무효화한다. 이전 법령의 늦은 요약이나 실패가 현재 법령을 덮어쓰지 못한다.

## 법령 품질 우선 기능의 정확한 범위

기존 자유 재서술 AI 요약은 재사용하지 않는다. 기본 표시 내용은 최신 공식 조문의 발췌다. 로컬 비과금 모델은 서버가 제공한 조문 블록 ID 전체의 순서만 제안할 수 있으며, 내용 변경·숫자 변경·블록 누락은 허용하지 않는다.

소비자의 청구·지급·권리·구제 관련 조문을 먼저 배치하는 평가 점수가 기본 순서보다 높을 때만 후보를 선택한다. 이는 **핵심 순서에 대한 제한적 평가**이며, 자유롭게 작성된 요약의 의미 정확성이나 법률 적정성을 인증하는 기능은 아니다. 추가 유료 모델을 자동 호출하지 않는다.

선택 결과는 원문 지문·언어·모델·평가 기준에 따라 공용 저장한다. 같은 조건에서는 공통 결과를 재사용하고, 모델이나 원문 등이 변경되면 별도로 평가한다. 동시 요청이 이미 선택된 결과를 낮은 점수로 덮어쓰지 못하도록 저장 잠금을 사용한다.

## 자동 검증

최종 격리 빌드 성공. 기본 기능 452/452, 검색·AI 근거 122/122, 안정성 52/52, 이번 수정 전용 33/33: 총 **659회 테스트 실행 통과**, 실패·취소·건너뜀 없음. 일부 UI 검사는 여러 단계에서 반복 실행하므로 659개의 서로 다른 기능을 검증했다는 뜻은 아니다.

TypeScript, 변경 소스 ESLint, 변경 내용 공백 검사도 통과했다. 신규 법령 UI 검사 5개는 실제 컴포넌트 콜백을 실행하면서 취소를 무시하는 지연 응답을 주입해 늦은 성공·실패·원문 응답·언어 변경·화면 종료를 검증한다. 전국 상권 조회 검사는 실제 서비스 함수와 SQL을 격리 SQLite에서 실행하지만 외부 제공기관의 실연결 검사는 아니다.

## 공개 데이터 및 운영 상태

- 공개 자료만 복사한 리허설: 저장 항목 사본 85,893개의 소속 지문 보존, 검색 문서 30,419건의 인덱스/투영 일치, SQLite/FTS 무결성 통과.
- 청년정책 2,749건에 날짜 출처 메타데이터 등을 정규화했다. 2,749건 모두 잘못된 미래 날짜였다는 뜻은 아니다. 실제 운영 DB 재검사에서 남은 정정 0건.
- 읽기 전용 검색 표본 4개는 모두 준비 상태로 후보를 반환했다. 검색 단계는 약 17–87ms였다. 전체 HTTP·AI 답변 시간이나 정확도 향상률을 측정한 수치가 아니다.
- 최종 확인에서 웹, 로컬 LLM 게이트웨이, Ollama, 외부 접속 터널이 모두 실행 중이었다. 헬스체크·메모리 감시·공개 자료 갱신·서울 자료 수집 타이머도 실행 중이었다.
- 공개 도메인 건강 확인 응답은 정상. 최종 확인 시 각 서비스의 자동 재시작 횟수는 0이었다. 장시간 부하·메모리 누수·재부팅 복구까지 검증한 것은 아니다.

비공개 복구 백업은 서버의 `.deploy-backups/rag-evidence.bT7t4IbQ`와 최종 `.deploy-backups/rag-evidence.aPtEklQT`에 보존했다. 배포 중에는 타이머의 기존 실행 상태를 보존·복원했고, 실패 시 코드 복구가 준비되어 있었다. 새 사용자 쓰기를 잃을 수 있으므로 실행 중 DB를 과거 백업으로 덮어쓰는 방식은 사용하지 않는다.

## 실제 브라우저 확인

- 초기 홈 편집 버튼 표시·실행, BORA Member 로그인 선택 창, 창 닫기 정상. 닫은 뒤 앱 내부 AI 메뉴와 정보 페이지를 이동해도 로그인 창이 재등장하지 않았다.
- 새로고침 없이 홈→창업 정보, 정보→홈, 안심→AI 상담 이동 확인.
- 창업 공고 전체 257건, 전국 102건인 표본에서 부산 지역 38건을 24건/14건으로 페이지 이동했다. 2페이지에서도 지도·지역 선택 유지. 지역 집계는 전국 공고를 별도 취급한다.
- 부산 2페이지에서 `부기테크` 검색 시 기존 1페이지의 대상 공고 1건을 찾고 1페이지로 돌아왔다. 현재 페이지의 카드만 검색하는 문제가 아님을 확인했다.
- 서울 상권 TOP 10, 1,650개 상권 안내, 업종 비율, 시간대 매출·유동인구가 계속 표시됐다.
- 법령 발췌는 접힌 상태로 시작했고 접기·펴기가 동작했다. 같은 주제를 다시 열면 저장된 공식 발췌 재사용 표시를 확인했다.
- 최종 보완 배포 후 예금자보호→채권추심 전환 시 채권추심 법령과 발췌가 일치했고, 발췌에 이전 예금자보호법이 섞이지 않았다. 강제로 지연시킨 경합은 자동 검사에서 별도로 검증했다.
- 기존 USD↔KRW 양방향 환산 유지 확인. 시험 후 기본 방향으로 돌려놓았다.

## 남은 확인과 제한

1. 현재 연결 가능한 브라우저는 비로그인 상태다. 로그인 전용 실제 AI 답변, 전국 점포 제공기관 응답, 로그인 후 집계/개인화 동작은 사용자 재로그인 후 재검증이 필요하다. 이전 감사에서 사용한 Chrome 세션은 현재 연결되지 않는다. 인증 우회나 세션 추출은 하지 않았다.
2. 고용24는 설정 OFF 및 `credential-unavailable` 상태다. 저장된 키의 공식 제공기관 전송 시험은 보안 승인에서 차단되어 실행하지 않았다. 사용자에게 공식 고용24 서버로의 1회 연결 시험 승인을 요청했으며 아직 응답받지 않았다. ON 전환도 하지 않았다.
3. DART 백필 진행, 일부 금융회사/K-Startup 보존 상한 경고는 남아 있다. 제공기관의 모든 데이터가 완전히 수집됐다고 해석하면 안 된다.
4. 다른 실제 계정/기기 간 저장·복원, 삭제·탈퇴, 개인정보 기억 ON 상태, 장시간 운영·복원·재부팅 시험은 이번 검증 범위에 포함하지 않았다.

따라서 코드 수정·배포 및 위 검증은 완료했지만, 모든 계정·모든 API·모든 AI 답변이 정상이라고 포괄적으로 단정하지 않는다.
