## 가상 자산 입력값

- 현금 12,000,000원 / 투자 6,000,000원 / 기타 2,000,000원 / 부채 5,000,000원
- 월소득 3,000,000원 / 고정비 1,000,000원 / 변동비 700,000원 / 상환 300,000원
- 총자산 20,000,000원 / 순자산 15,000,000원 / 월 여유 1,000,000원

가상 입력은 계정에 저장하거나 AI에 전송하지 않았습니다. 마이데이터·오픈뱅킹·실제 계좌와 연동되지 않았습니다.

## 출처와 현재성

각 화면의 원래 URL과 SHA-256 값은 `capture-manifest.json`에 있습니다.
공식 공고·상품 조건·환율·수집 건수는 변경될 수 있습니다. 신청이나 계약 전에는 제공기관 원문을 확인해야 합니다.
캡처는 전체 기능의 정상 동작이나 장기 운영 안정성을 보증하지 않습니다.
사이트 링크는 서버 종료 후 열리지 않을 수 있습니다.
